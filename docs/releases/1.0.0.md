# AssetFlow 1.0.0

**Your creative work, in order.** A local Windows workspace by odyworks for designers, 3D artists, video editors, and developers.

## Download / Unduh

- **AssetFlow_1.0.0_x64-setup.exe** — installer for the current Windows user / installer untuk pengguna Windows saat ini.
- **AssetFlow.exe** — standalone executable / executable standalone.
- **SHA256SUMS.txt** — SHA-256 hashes for both Windows packages / checksum kedua paket Windows.
- **AssetFlow-demo.mp4** — silent native-app tour using disposable sample content / demo aplikasi asli tanpa audio dengan proyek contoh.

Target: **Windows x64**. Microsoft Edge WebView2 Runtime is required; 3D inspection needs WebGL hardware acceleration. Packages are **unsigned**. This release was exercised locally on Windows 11; it does not claim native ARM64 validation. FFmpeg/ffprobe is optional and is not bundled.

Target **Windows x64**. Membutuhkan WebView2; inspector 3D membutuhkan akselerasi WebGL. Paket **belum ditandatangani secara digital**. Pengujian lokal dilakukan pada Windows 11; tidak ada klaim pengujian ARM64. FFmpeg/ffprobe bersifat opsional dan tidak disertakan.

## Included / Fitur

- Recursive local browsing, grid/list, search, category filters, statistics, favorites, and recent projects.
- GLB/GLTF studio inspector, image previews, and video/audio playback when supported by local codecs.
- Organization preview, explicit confirmation, safe conflict names, GLTF/GLB dependency grouping, and persistent undo for the most recent organization.
- Native folder notifications, read-only Project Health Check, and Collect & Package with relative paths and streaming SHA-256.
- Windows Open With, opt-in technical metadata through local ffprobe, and printable HTML contact sheets.
- Ctrl+K command palette, keyboard navigation, and bilingual documentation.

Semua operasi berjalan lokal: tanpa akun, cloud sync, layanan AI, atau database. Scan hanya membaca. Pemindahan membutuhkan preview dan konfirmasi. File tujuan yang sudah ada tidak ditimpa dan tidak ada operasi hapus file.

## Limits / Batas dukungan

- Only GLTF/GLB resource dependencies are analyzed. Blender, Adobe, video-editor, and source-code references require manual review. Try organization on a copy first.
- Move batches and undo are not atomic. Earlier completed moves remain if a later move fails.
- Packages are folders, not ZIP archives. Failed/cancelled collections retain marked partial output; only a valid final manifest with `complete: true` marks success.
- Contact sheets export HTML; PDF is produced through browser printing.
- Viewer compatibility and memory usage depend on file contents, codecs, hardware, and active features.

Analisis dependency otomatis hanya untuk GLTF/GLB. Packaging menghasilkan folder, bukan ZIP. Contact sheet menghasilkan HTML, dengan Save as PDF melalui browser. Rincian batas dan prosedur aman ada di panduan.

Build binaries match the tested local release artifacts from application source commit `65eb690`; subsequent commits update documentation and launch assets. No new performance benchmark is claimed.
