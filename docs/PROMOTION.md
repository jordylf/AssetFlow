## Short post — English

I built AssetFlow because creative project folders get messy fast.

It is a local Windows app for browsing references, textures, models and documents, inspecting GLB/GLTF files, and reviewing a file organization plan before anything moves. It also has undo, folder updates, health checks and asset collection with checksums.

No account or cloud required. The code is MIT licensed, and Windows builds are available.

Demo and downloads: https://github.com/jordylf/AssetFlow

I'd appreciate feedback from designers and 3D artists: what makes finding or handing over your project files frustrating? If this helps your workflow, consider starring the repository.
